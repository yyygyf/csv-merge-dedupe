# n8n CSV snapshot reconciliation demo

A synthetic CSV comparison sample developed with Codex. Locally executed with n8n 2.38.7 and Node.js 24.19.0 on Windows x64. The sample produced one added, one removed, one changed and one unchanged record. This is a capability sample, not a client deployment.

The package contains an importable workflow, verification script and a projection of its actual execution results.
